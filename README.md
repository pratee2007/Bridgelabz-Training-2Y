# Bridgelabz-Training-2Y

This repository contains Java data structures & algorithms practice problems and solutions.

Recommended structure
- src/problems/    — problem statements, notes, and input files
- src/solutions/   — Java solution files (simple javac-based layout)
- examples/        — sample inputs/outputs
- docs/            — notes, explanations, references

Quick start (Windows):
1. Edit or add .java files under src/solutions
2. Run run.bat to compile and run the default sample

If you want, I can scaffold more problems or convert this to a Maven/Gradle project.
